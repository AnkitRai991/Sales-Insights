Overview & Purpose

The Sales Insights Dashboard is designed to convert raw sales data into actionable insights for business growth.
It helps analyze key business metrics such as:

Revenue trends over time
Product performance
Customer purchasing behavior
Region-wise sales distribution
Profitability insights

This project is useful for business stakeholders, sales teams, and data analysts to improve decision-making efficiency.

🧰 Tools & Technologies Used
📊 Microsoft Excel – Data cleaning and initial analysis
🔄 Power Query – ETL (Extract, Transform, Load) for data preparation
📈 Power BI – Interactive dashboards and data visualization
📊 Key Features
Cleaned and transformed raw sales data using Excel and Power Query
Built structured datasets for accurate reporting and analysis
Designed interactive Power BI dashboards for sales insights
Identified revenue decline patterns and growth opportunities
Analyzed product-wise and region-wise performance
Improved visibility into customer buying behavior
📈 Dashboard Insights
Total revenue and sales performance tracking
Top-performing and low-performing products
Region-wise sales distribution
Monthly/seasonal sales trends
Customer purchase behavior analysis
🚀 Business Impact
Improved visibility into overall sales performance
Helped identify key growth opportunities
Supported faster and data-driven business decisions
Enhanced reporting efficiency using automated Power Query workflows
